# 语言与论证指南

本指南结合本校论文可用全文的分类阅读及 Humanizer-zh 编辑原则独立整理，MEM与其他工程硕士核心语料、MBA/EMBA题材辅助语料分开使用。实际数量、完整性和阅读范围见来源卡，不将所有文件统称完整MEM论文。样本中的口号、重复、过时格式和过强结论不照搬；“像论文”并不等于证据充分。以下示例均为虚构教学材料，不取自原论文或用户数据。

同时使用 [全文质量、统一风格与逻辑连贯](manuscript-quality.md) 核查严谨性、逻辑性、专业性、自然表达、风格统一和跨段跨章联系。先解决内容和推理，再处理句子；局部措辞优化不能代替整稿审阅。

## 从段落的信息任务下手

| 发现的问题 | 修改方向 | 保留边界 |
|---|---|---|
| 一段背景可原样用于任何行业 | 从已有材料中的业务对象和矛盾切入 | 背景有真实趋势、时间和来源则保留 |
| 抽象名词连续出现，读者仍不知谁做了什么 | 展开动作、流程与对象 | 不猜测原稿未提供的参与者或技术实现 |
| 每段都用“首先、其次、最后”或假对比 | 让顺序、并列、转折由实际关系决定 | 确有步骤或对照时保留连接词 |
| 研究方法只是工具名清单 | 解释工具处理什么材料、回答什么问题 | 没有实际实施就写建议或删除实施宣称 |
| 每项表格数值在正文再报一遍 | 选主要差异，解释其含义和约束 | 关键分母、单位与不利结果仍可见 |
| 每节末尾都称“具有重要意义” | 写本节已建立的认识及后文要处理的问题 | 真实应用意义可保留，不能人为降格 |
| 文献一篇一段，只列作者说法 | 围绕问题综合一致、差异与不足 | 不编造作者关系，不扩大引文支持 |
| 流程回执进入正文 | 写业务及研究本身，文件路径等移研究档案 | 方法、必要复现信息、披露不因此删除 |
| 限制在每段重复 | 在方法、表注及关键结论处合理归位 | 远处有局限不能掩护眼前的无条件断言 |
| 为“自然”改口语或混用术语 | 保持正式中文，同一概念同一名称 | 引文原貌和学科惯例优先 |

图表也要参与解释：图前引出所要说明的流程或问题，图后讲清主要关系，不只留下“如下图所示”。方案应回应已经诊断的问题；研究展望指向实际尚未完成的评价或分析，不能只写通用愿望。

语料中的依据与反例逐项见 [规则依据与限制](rule-evidence.json)。这是体裁归纳；因果约束、引用保真、披露和隐私是独立质量原则，不声称由这些样本证明。

这些是判断入口，不是正则替换指令。句长、四字词、被动句、排比、分号、破折号和“本文”都可以有用。没有问题的表达不需要修改。

## 修改示例

**流程说明**

原文：在数字化转型的大背景下，企业通过信息赋能机制的构建实现了服务承接闭环。客户可以保存设备型号，客服下次查询时读取已保存的信息。

修订：客户可以保存设备型号，客服在后续查询时读取这些信息。

核对：仅压缩了没有独立信息的铺垫；没有增添工时减少、查询准确率或转化结果。

**观察结果**

原文：两组的再次购买比例分别为18%和14%，前者高4个百分点。两组并非随机分配，因此该差异可能与购买历史有关。

处理：可以原样保留。18%与14%的差距是4个百分点，不是4%；不得删去组间选择限制后改写为措施带来4个百分点提升。

**理论联系**

原文：流程体现了精益理念。客户重复填写相同资料，系统增加了资料保存功能。是否减少填写时间尚未测量。

修订：为减少客户重复填写相同资料，系统增加了资料保存功能。该做法针对重复输入环节，但现有资料尚不能评价填写时间的变化。

核对：目的与实测结果分开。若原材料并未确认开发目的，第一句改为“系统增加了资料保存功能，可供后续使用”，不反推团队动机。

**引用与确定程度**

原文：甲等[3]指出，维护便利性可能影响继续使用意愿。本文尚未测量维护便利性。

处理：不能改为“维护便利性决定了用户忠诚”。引文支持、可能性和本研究未测量事实都要保留。

**不能靠润色补救的段落**

原文：优化后所有指标显著改善，证明该模式适用于所有制造企业。

处理：若没有指标、检验和外部样本，登记“证据不足”；从用户已给材料收窄结论，不能自己制造数值、检验或泛化依据。

## 引用和事实核对

语言修订前后核查六类不变量：数字/单位；对象/时间/范围；否定/条件；比较/因果；来源归因/引文；实施/计划/完成状态。逐字相等不必然语义相等，词语变化也不必然失真，需要结合命题判断。

引用格式与引用真实性分开：题录存在、读到原文、命题获得支持、格式正确是四项不同检查。只读摘要不说通读全文。重排段落后重新核对首次引用顺序、正文与文末条目双向对应。格式工具不认证GB/T 7714全文著录合规。
