# 全文质量、统一风格与逻辑连贯

本模块落实论文表达的六项要求。适用于语言润色和内容优化；先判断命题及其联系是否成立，再处理措辞。局部段落任务按可取得的上下文检查，全稿任务还需在逐章修改后连续通读。这里的“自然”指清楚、具体、有依据的学术表达，不认定真人概率或模仿未建立的个人文风。

## 六项质量要求

| 维度 | 实际检查与修订 |
|---|---|
| 严谨性 | 概念、对象、量纲、时间与范围明确；观察、解释、推断及建议分清；结论确定程度与证据相称。不用流畅措辞遮盖矛盾、未知或缺证。 |
| 逻辑性 | 理由能支持判断，比较条件相容，结论回答研究问题。区分顺序、并列、相关与因果；补充已有材料中的推理，无法建立的关系收窄并登记。 |
| 专业性 | 术语定义及理论、模型、方法使用准确，在当前分析中有实际作用。专业性体现在解释清楚和选择有据，不能靠新造术语或叠加概念提高。 |
| 自然性 | 主语、动作及指代清楚，句法符合中文表达；句子长短随意思变化，作者判断通过具体解释体现。保持正式语体，保留必要的限定与专业词。 |
| 风格统一 | 全稿采用稳定的概念称谓、叙述视角和正式程度；时态随实际状态正确变化。方法、业务、结果及结论各有任务，不要求全部章节使用同一种句型。 |
| 连贯性 | 段落在已有信息上推进，章内及跨章的对象和问题可追踪；诊断引出措施，方法支持评价，讨论解释发现，摘要与结论回扣正文。过渡交代真实关系。 |

以上是编辑与研究质量要求。语料观察及适用限制另见 [规则依据](rule-evidence.json)，学院格式依据另见 [格式指南](formatting.md)；不将六项要求伪装成学院公布的语言评分表或新一轮统计发现。

## 从全文到句子检查

**全文。** 先从现稿确认研究对象、核心问题、采用的方法、主要发现及结论，找出对应章节。检查摘要和结论是否扩大了对象、改变结果方向或新增未评价的效益。沿用已授权的结构；发现实质结构问题时给出依据，不为语言统一擅自重建研究。

**章节与相邻小节。** 检查每部分解决什么问题、采用哪些已定义对象、为下一部分提供什么分析。理论要在方法或解释中实际使用，措施要回应诊断，评价要检验对应目标。必要的研究设计说明可以前置；不能为让顺序好看而把回顾分析写成当时预先决策。

**段落。** 判断段落是否推进一个可辨认的任务，句子之间的比较、转折、解释和条件能否成立。将重复判断合并，把支撑材料与相应判断放近；缺少根据时回源或收窄。主题句、证据、解释及小结按内容安排，不让每段都套同一流程。

**句子。** 最后处理指代、搭配、信息负荷、冗余修饰和机械句式。因果未建立时，即使删掉“因此”，后面的无条件结论仍须修改。改完重新对照六类语义不变量，见 [语言指南](writing-guide.md)。

## 统一风格时保留什么区别

采用项目已有表达规范和作者已确认的用语。长稿可在工作记录中简列“概念—采用名称—必要区别”，不用每次新建大型风格档案；没有作者写作样本时采用平实、准确、克制的学术中文。

- 同一概念统一称谓；客户、会话、订单及消息等不同分析单位继续区分。不能将不同单位改叫同一类“用户”来制造一致。
- 区分业务实施者与研究叙述者。描述实际业务写参与者和动作，说明研究选择可用“本文”；不凭措辞补造作者参与、访谈或现场经历。
- 既有事实、已完成分析、待实施方案及未来建议使用各自准确的状态。“统一时态”不能把计划写成完成。
- 正文、表图、摘要及结论的术语、缩写、组名和确定程度相互对应。直接引语保留原貌，缩写首次定义后按学科惯例使用。
- 统一正式程度，不把专业表述改成聊天、广告或咨询口号，也不以故意不规则、错字或口语制造“真人感”。

## 显性表达弊端的判断入口

以下按信息和推理作用判断，不作为禁词表或批量替换规则。

| 常见表现 | 修改依据 |
|---|---|
| 宏观背景层层铺垫，结尾拔高为普遍意义 | 压缩无独立信息的铺垫，落到具体对象；贡献限于已经建立的认识。 |
| “机制、体系、协同”等名词相互解释，仍不知谁做什么 | 用已有事实展开对象、动作和关系；有定义和分析用途的概念保留。 |
| 反复使用“不是……而是……”、整齐三点或对称排比 | 只有确有区别或并列关系时使用；真实步骤、分类与多目标取舍保留。 |
| 每段都先宣告重要性，再换词复述，最后空泛总结 | 保留新增事实、分析和必要小结，去掉没有推进的复读。 |
| “因此、进而、综上”连接了证据未支持的结论 | 核查并重写推理关系；缺证时留下有范围的判断，不用过渡词补缺口。 |
| 生硬的新术语、跨学科类比或抽象词使表述显得高深 | 按实际定义和方法使用通行术语；无分析作用的包装展开或删去。 |
| 各章像不同作者：称谓、视角、口语程度和断言强度漂移 | 按同一表达基准通读修订，同时保留各章功能及证据性质的区别。 |
| 为求变化不断换同义词，导致指代或概念改变 | 用固定术语维持对象连续；通过分析内容推进，避免靠换名称变化。 |
| 写入答题口吻、“下面将为您”或润色过程的自我说明 | 改为论文需要的内容；真正说明研究内容、方法或章节安排的句子按需保留。 |
| 逐格复述表格、逐篇排列文献、每段重讲所有限制 | 选主要发现并解释；综合文献支持关系；限制合理归位且关键结论旁仍可见。 |

例如，前节已发现维修资料重复填写、后节说明保存功能设计时，可直接交代该功能针对重复填写环节。若尚未测量服务耗时，过渡和结尾均不能写成已提高服务效率。连续性来自同一问题被继续处理，不依赖每节重写背景或“意义重大”。

## 完成判据

语言优化完成须在实际处理范围内说明：关键命题及限制是否保真；推理是否可追踪；专业词是否准确；表达是否自然；全文用语和语气是否一致；相邻段落、章节与摘要结论是否连贯。问题可定位到章、节或段，给必要改例和未决项，不强制逐词展示。

全稿任务同时保留逐章审阅和整稿连续阅读的真实记录。数值匹配、词频下降或局部句子通顺不能代替这两项；没有读取的部分不标为通过。不要求每段都改，不以改动字数、统一句式或自评分作为验收依据。记录方法见 [验收说明](acceptance.md)。
