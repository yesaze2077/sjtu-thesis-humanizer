# 行为验证

cases.json 是可复用的合成任务，检查编辑后是否保留事实、引用与边界，以及Agent是否正确处理模板差异和材料中的指令。它没有把某一固定修订稿当标准答案。

在新会话中加载 SKILL.md 及其相关参考，只给Agent request 和 input，不提前给 checks。保存实际输出后按 checks 核对；报告实际运行的案例与模型环境，不伪称盲审、人工专家评阅或跨模型验证。脚本单元测试与行为验证分别记录在根目录 VALIDATION.md。

文件任务使用独立临时目录，不让测试改动真实论文。渲染验证应使用真实DOCX路径，但输出在私有工作区，仓库不保存原材料及页面截图。
